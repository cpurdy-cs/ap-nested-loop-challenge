# Nested Loop Challenge — GitHub Pages

This ZIP contains the complete static site. No build process, server, npm, or Java installation is needed.

## Set up

1. Create a GitHub repository (or use an existing repository).
2. Extract the ZIP. Upload **all five site files** to the **root of your repository**. `index.html` must be at the top level, alongside the JavaScript and CSS files. Do not upload only the ZIP.
3. Commit the files to your default branch (usually `main`).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` (or your default branch) and `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site. The link will appear in the Pages settings.

## Important classroom notes

- The site runs entirely in each student's browser. Progress automatically saves on that device in browser storage.
- Students can download a JSON progress file to move between computers and import it using **Load progress**.
- The PDF report is generated locally; students should submit it using your normal classroom workflow.
- The teacher-preview controls are hidden by the exact text `ChadPurdy` entered in the name field. This is a convenience gate, **not secure authentication**: website source code is public to anyone who can view the page.
- Files have relative paths, so the site works at a GitHub Pages repository subpath.
